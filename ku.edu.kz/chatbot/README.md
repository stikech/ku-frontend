# ИИ-помощник СКГУ (виджет чата для ku.edu.kz)

Плавающая кнопка **справа снизу** на сайте. Открывает чат-панель на **⅓ ширины
экрана**. Студент задаёт вопрос — помощник ищет по всем страницам зеркала сайта
(357 страниц: разделы, новости, события, apply/dormitories/astra/mba/is),
даёт краткий ответ и **ссылки-источники строго с этого сайта**.

## Как это работает

```
вопрос студента
      │
      ▼
поиск по индексу (BM25) ← chatbot/data/index.json (собирается из HTML страниц)
      │  топ-5 релевантных страниц
      ▼
локальная модель Ollama (qwen2.5:1.5b) пересказывает кратко
      │
      ▼
ответ + карточки-источники (ссылки открывают страницы сайта)
```

* Нет Ollama или модели → помощник остаётся работоспособным: отвечает
  «режимом поиска» (выдержки из страниц + источники).
* Никаких внешних сервисов: всё считается локально.

## Файлы

| файл | назначение |
|---|---|
| `chatbot.js` | сам виджет: кнопка, панель, поиск, запрос к модели |
| `chatbot.css` | стили виджета (все классы с префиксом `kwc`) |
| `data/index.json` | поисковый индекс (страницы, чанки, обратный индекс) |
| `tools/build_index.py` | сборка индекса из HTML зеркала |
| `tools/inject.py` | подключение виджета ко всем страницам (идемпотентно) |

## Обслуживание

**Пересобрать индекс** (после обновления страниц сайта):

```bash
python3 Sites/ku-frontend/ku.edu.kz/chatbot/tools/build_index.py
```

**Добавить кнопку на новые страницы:**

```bash
python3 Sites/ku-frontend/ku.edu.kz/chatbot/tools/inject.py          # добавить
python3 Sites/ku-frontend/ku.edu.kz/chatbot/tools/inject.py --remove # убрать
```

## Настройки (в начале `chatbot.js`, объект `CFG`)

| ключ | описание |
|---|---|
| `ollama` | адрес локальной Ollama (`http://localhost:11434`) |
| `model` | модель пересказа (`qwen2.5:1.5b`). Можно поставить крупнее, например `qwen2.5:3b` |
| `sourceMode` | `'local'` — источник открывает локальное зеркало; `'canonical'` — оригинальный адрес на живом ku.edu.kz |
| `topPages` / `maxSources` | сколько страниц в контекст / сколько источников показывать |

## Если что-то не работает

* **Кнопки нет на странице** — страница добавлена до inject или это служебная
  страница (логин/gtm): запустите `inject.py`, Ctrl+F5.
* **«Не удалось загрузить базу знаний»** — сайт должен открываться через
  `python -m http.server` из папки `Sites/ku-frontend` (порт 8000).
* **Всегда «режим поиска»** — модель не запущена. Проверить:
  `ollama list`, поднять: `ollama serve`, скачать: `ollama pull qwen2.5:1.5b`.
  Если Ollama стоит на другом порту — поправьте `CFG.ollama`.
* **Ответ медленный** — первый запрос после старта Ollama прогревает модель
  (~10–20 с), дальше быстрее. Для более качественных/долгих текстов поставьте
  `qwen2.5:3b` в `CFG.model` (скачав её через `ollama pull`).
