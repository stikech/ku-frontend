# ИИ-помощник Kozybayev University (виджет чата)

Плавающая кнопка с совой **справа снизу** на сайте. Открывает компактное окно
чата на компьютере и полноэкранный чат на телефоне. Студент задаёт вопрос —
помощник ищет по всем страницам зеркала сайта
(357 страниц: разделы, новости, события, apply/dormitories/astra/mba/is),
отправляет вопрос в Gemma 4 на сервере компьютера-хоста и показывает ссылки-источники
из базы Kozybayev University. При недоступности API остаётся локальный поиск
по зеркалу сайта с выдержками и ссылками.

## Как это работает

```
вопрос студента → API зеркала → поиск по базе KU → Gemma 4 → ответ и источники
```

* Если API недоступен, помощник переключается на локальный поиск по индексу
  `chatbot/data/index.json`.
* GitHub Pages не хранит API-ключ модели. Запросы идут по HTTPS через Tailscale Funnel.

## Файлы

| файл | назначение |
|---|---|
| `chatbot.js` | сам виджет: кнопка, панель, запрос к Gemma API и локальный fallback |
| `chatbot.css` | стили виджета (все классы с префиксом `kwc`) |
| `bird-idle.png` | иконка помощника в кнопке, заголовке и ответах |
| `data/index.json` | поисковый индекс (страницы, чанки, обратный индекс) |
| `tools/build_index.py` | сборка индекса из HTML зеркала |
| `tools/inject.py` | подключение виджета ко всем страницам (идемпотентно) |

## Обслуживание

**Пересобрать индекс** (после обновления страниц сайта):

```bash
python3 Sites/ku-frontend/ku.edu.kz/chatbot/tools/build_index.py
```

**Добавить кнопку на новые страницы:**

```bash
python3 Sites/ku-frontend/ku.edu.kz/chatbot/tools/inject.py          # добавить
python3 Sites/ku-frontend/ku.edu.kz/chatbot/tools/inject.py --remove # убрать
```

## Настройки (в начале `chatbot.js`, объект `CFG`)

| ключ | описание |
|---|---|
| `aiApi` | адрес API сервера Gemma (`https://wizer.tail5fd495.ts.net`) |
| `model` | имя модели, отображаемое в статусе (`google/gemma-4-e4b`) |
| `sourceMode` | `'local'` — источник открывает локальное зеркало; `'canonical'` — оригинальный адрес на живом ku.edu.kz |
| `topPages` / `maxSources` | сколько страниц в контекст / сколько источников показывать |

## Если что-то не работает

* **Кнопки нет на странице** — страница добавлена до inject или это служебная
  страница (логин/gtm): запустите `inject.py`, Ctrl+F5.
* **«Не удалось загрузить базу знаний»** — сайт должен открываться через
  `python -m http.server` из папки `Sites/ku-frontend` (порт 8000).
* **Всегда «режим поиска»** — проверьте доступность `/api/ai/status` на адресе
  Funnel, запуск LM Studio и CORS для `https://stikech.github.io`.
* **Нет ответа** — проверьте, что LM Studio и Gemma запущены на компьютере,
  а Funnel доступен по HTTPS. Не добавляйте API-ключ в этот репозиторий.
