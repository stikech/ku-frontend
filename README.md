# Зеркало сайта СКГУ им. М. Козыбаева (ku.edu.kz) + ИИ-помощник

Локальное зеркало официального сайта университета (HTTrack) с добавленным
**ИИ-чат-помощником для студентов**.

## Где смотреть

* Локально: `python -m http.server` в корне репозитория → `http://localhost:8000/ku.edu.kz/ru/`
* На GitHub Pages (после включения Pages): `https://stikech.github.io/ku-frontend/ku.edu.kz/ru/`

## ИИ-помощник

Плавающая кнопка справа снизу → чат на ⅓ ширины экрана. Отвечает строго по
страницам этого сайта (RAG-поиск по индексу + локальная модель Ollama,
если доступна; без неё — режим поиска с источниками).

Подробнее: [ku.edu.kz/chatbot/README.md](ku.edu.kz/chatbot/README.md)

## Обслуживание

| действие | команда |
|---|---|
| пересобрать поисковый индекс | `python3 ku.edu.kz/chatbot/tools/build_index.py` |
| добавить кнопку на новые страницы | `python3 ku.edu.kz/chatbot/tools/inject.py` |
| убрать кнопку | `python3 ku.edu.kz/chatbot/tools/inject.py --remove` |

## Минутка правды

у Северо-Казахстанского университета им. М. Козыбаева (ku.edu.kz).
